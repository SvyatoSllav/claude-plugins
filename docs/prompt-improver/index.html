Prompt Improver

Turns a rough request into a clear, structured prompt with role, context, constraints and output format.

Add to ClaudeUse in ChatGPT

What it does

Paste a simple prompt and get an optimized version that any AI assistant understands better: the goal, the context, the audience, constraints, examples and the exact output format. You also get a short explanation of what changed and 2 variants for different use cases, so you learn to write better prompts yourself.

Looking for the “Prompt Maker” GPT?

Custom GPTs in ChatGPT are being retired. Prompt Improver does the same job and works in both Claude and ChatGPT, with clear instructions and no sign-up.

Try asking

  • “Improve this prompt”
  • “Turn "write a marketing email" into a detailed prompt”
  • “Make a prompt for summarizing research papers”
  • “Why is my prompt giving vague answers?”

Add it to Claude

Claude (web, desktop, mobile)

Open Customize → Directory in Claude, search for Prompt Improver and add it. The plugin also works in Cowork and in Claude Code.

Claude Code

/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install prompt-improver@plugins-factory

Use it in ChatGPT

Open Plugins in ChatGPT and search for Prompt Improver. Listing in the ChatGPT directory is in review; the package is available in the source repository.

FAQ

Is it free?

Yes. Prompt Improver is free and open source under the MIT license. It runs inside your existing Claude or ChatGPT account.

Does it collect my data?

No. It is a set of instructions for the assistant; it does not call external services or store anything. Your conversation stays in Claude or ChatGPT.

Is this the same as the "Prompt Maker" GPT?

No, it is an independent assistant built to do the same job after custom GPTs were retired. It works in Claude as well as ChatGPT.

Which languages does it support?

It follows the language you write in. English is the default.
