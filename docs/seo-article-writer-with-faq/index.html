SEO Article Writer with FAQ

Writes search-optimized articles for a keyword with an outline, meta title, meta description and FAQ section.

Add to ClaudeUse in ChatGPT

What it does

Give a target keyword and audience. You get a structured long-form article: search intent, outline, meta title and description, H2/H3 structure with related keywords, a FAQ block ready for FAQ schema, and internal linking ideas. Written for people first, following helpful-content and E-E-A-T principles.

Looking for the “Fully SEO Optimized Article including FAQ's” GPT?

Custom GPTs in ChatGPT are being retired. SEO Article Writer with FAQ does the same job and works in both Claude and ChatGPT, with clear instructions and no sign-up.

Try asking

  • “Write an SEO article for "best running shoes for flat feet"”
  • “Create an outline and FAQ for "how to start a vegetable garden"”
  • “Write a 1,500-word article about remote work productivity for managers”
  • “Give me meta title and description options for this article”

Add it to Claude

Claude (web, desktop, mobile)

Open Customize → Directory in Claude, search for SEO Article Writer with FAQ and add it. The plugin also works in Cowork and in Claude Code.

Claude Code

/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install seo-article-writer-with-faq@plugins-factory

Use it in ChatGPT

Open Plugins in ChatGPT and search for SEO Article Writer with FAQ. Listing in the ChatGPT directory is in review; the package is available in the source repository.

FAQ

Is it free?

Yes. SEO Article Writer with FAQ is free and open source under the MIT license. It runs inside your existing Claude or ChatGPT account.

Does it collect my data?

No. It is a set of instructions for the assistant; it does not call external services or store anything. Your conversation stays in Claude or ChatGPT.

Is this the same as the "Fully SEO Optimized Article including FAQ's" GPT?

No, it is an independent assistant built to do the same job after custom GPTs were retired. It works in Claude as well as ChatGPT.

Which languages does it support?

It follows the language you write in. English is the default.
