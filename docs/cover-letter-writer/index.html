Cover Letter Writer

Writes a tailored, concise cover letter from your resume and the job posting, in a natural voice.

Add to ClaudeUse in ChatGPT

What it does

Paste the job description and your resume or a few facts about yourself. You get a one-page cover letter that connects your real experience to what the employer needs, opens with a specific hook instead of clichés, and ends with a confident call to action. Choose formal, warm or startup tone.

Looking for the “Cover Letter” GPT?

Custom GPTs in ChatGPT are being retired. Cover Letter Writer does the same job and works in both Claude and ChatGPT, with clear instructions and no sign-up.

Try asking

  • “Write a cover letter for this job using my resume”
  • “Make my cover letter shorter and more specific”
  • “Write a cover letter for a career change into UX design”
  • “Give me three opening lines that aren't cliché”

Add it to Claude

Claude (web, desktop, mobile)

Open Customize → Directory in Claude, search for Cover Letter Writer and add it. The plugin also works in Cowork and in Claude Code.

Claude Code

/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install cover-letter-writer@plugins-factory

Use it in ChatGPT

Open Plugins in ChatGPT and search for Cover Letter Writer. Listing in the ChatGPT directory is in review; the package is available in the source repository.

FAQ

Is it free?

Yes. Cover Letter Writer is free and open source under the MIT license. It runs inside your existing Claude or ChatGPT account.

Does it collect my data?

No. It is a set of instructions for the assistant; it does not call external services or store anything. Your conversation stays in Claude or ChatGPT.

Is this the same as the "Cover Letter" GPT?

No, it is an independent assistant built to do the same job after custom GPTs were retired. It works in Claude as well as ChatGPT.

Which languages does it support?

It follows the language you write in. English is the default.
