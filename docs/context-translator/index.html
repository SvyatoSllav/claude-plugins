Context Translator

Translates text between any languages while keeping tone, formatting and meaning, with notes on tricky phrases.

Add to ClaudeUse in ChatGPT

What it does

Paste text or a document and name the target language. You get a faithful translation that keeps the tone (formal, casual, marketing, legal), the formatting and the terminology, plus short notes on idioms and phrases that have no direct equivalent. Works for emails, documents, product copy, subtitles and chat messages.

Looking for the “Translate GPT” GPT?

Custom GPTs in ChatGPT are being retired. Context Translator does the same job and works in both Claude and ChatGPT, with clear instructions and no sign-up.

Try asking

  • “Translate this email into Spanish, keep it formal”
  • “Translate this product description into Japanese for a US brand”
  • “Translate this paragraph into French and explain the idioms”
  • “What is the most natural way to say this in German?”

Add it to Claude

Claude (web, desktop, mobile)

Open Customize → Directory in Claude, search for Context Translator and add it. The plugin also works in Cowork and in Claude Code.

Claude Code

/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install context-translator@plugins-factory

Use it in ChatGPT

Open Plugins in ChatGPT and search for Context Translator. Listing in the ChatGPT directory is in review; the package is available in the source repository.

FAQ

Is it free?

Yes. Context Translator is free and open source under the MIT license. It runs inside your existing Claude or ChatGPT account.

Does it collect my data?

No. It is a set of instructions for the assistant; it does not call external services or store anything. Your conversation stays in Claude or ChatGPT.

Is this the same as the "Translate GPT" GPT?

No, it is an independent assistant built to do the same job after custom GPTs were retired. It works in Claude as well as ChatGPT.

Which languages does it support?

It follows the language you write in. English is the default.
