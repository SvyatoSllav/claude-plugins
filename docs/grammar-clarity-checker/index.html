Grammar & Clarity Checker

Fixes grammar, spelling and punctuation, explains each change and suggests clearer wording.

Add to ClaudeUse in ChatGPT

What it does

Paste any text: an essay, an email, a cover letter or a post. You get a corrected version, a short list of what changed and why, and optional suggestions to make sentences clearer without changing your voice. Works for US and UK English. Free to use.

Looking for the “Grammar Checker” GPT?

Custom GPTs in ChatGPT are being retired. Grammar & Clarity Checker does the same job and works in both Claude and ChatGPT, with clear instructions and no sign-up.

Try asking

  • “Check my essay for grammar errors”
  • “Is this paragraph grammatically correct?”
  • “Make this email clearer without changing the tone”
  • “Explain the difference between "affect" and "effect" with examples”

Add it to Claude

Claude (web, desktop, mobile)

Open Customize → Directory in Claude, search for Grammar & Clarity Checker and add it. The plugin also works in Cowork and in Claude Code.

Claude Code

/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install grammar-clarity-checker@plugins-factory

Use it in ChatGPT

Open Plugins in ChatGPT and search for Grammar & Clarity Checker. Listing in the ChatGPT directory is in review; the package is available in the source repository.

FAQ

Is it free?

Yes. Grammar & Clarity Checker is free and open source under the MIT license. It runs inside your existing Claude or ChatGPT account.

Does it collect my data?

No. It is a set of instructions for the assistant; it does not call external services or store anything. Your conversation stays in Claude or ChatGPT.

Is this the same as the "Grammar Checker" GPT?

No, it is an independent assistant built to do the same job after custom GPTs were retired. It works in Claude as well as ChatGPT.

Which languages does it support?

It follows the language you write in. English is the default.
