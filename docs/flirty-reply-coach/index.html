Flirty Reply Coach

Helps you write witty, respectful replies and openers for dating apps and chats, in your own voice.

Add to ClaudeUse in ChatGPT

What it does

Paste a match's profile or your chat and get 3–5 reply options in different styles: playful, warm, curious or direct. Each option is short, specific to the conversation and sounds like a real person. Includes tips on keeping the conversation going and asking someone out, always respectful. For adults 18+.

Looking for the “Rizz GPT Relationship Advice” GPT?

Custom GPTs in ChatGPT are being retired. Flirty Reply Coach does the same job and works in both Claude and ChatGPT, with clear instructions and no sign-up.

Try asking

  • “Help me craft an opening line for this profile”
  • “How do I turn this dry chat into something fun?”
  • “Give me a witty reply to this message”
  • “How do I ask them out without being awkward?”

Add it to Claude

Claude (web, desktop, mobile)

Open Customize → Directory in Claude, search for Flirty Reply Coach and add it. The plugin also works in Cowork and in Claude Code.

Claude Code

/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install flirty-reply-coach@plugins-factory

Use it in ChatGPT

Open Plugins in ChatGPT and search for Flirty Reply Coach. Listing in the ChatGPT directory is in review; the package is available in the source repository.

FAQ

Is it free?

Yes. Flirty Reply Coach is free and open source under the MIT license. It runs inside your existing Claude or ChatGPT account.

Does it collect my data?

No. It is a set of instructions for the assistant; it does not call external services or store anything. Your conversation stays in Claude or ChatGPT.

Is this the same as the "Rizz GPT Relationship Advice" GPT?

No, it is an independent assistant built to do the same job after custom GPTs were retired. It works in Claude as well as ChatGPT.

Which languages does it support?

It follows the language you write in. English is the default.
