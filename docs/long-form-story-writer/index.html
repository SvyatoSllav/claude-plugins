Long-Form Story Writer

Writes long, coherent stories chapter by chapter from your premise, keeping characters and plot consistent.

Add to ClaudeUse in ChatGPT

What it does

Give a premise, a genre and a mood, and get a story written in chapters with a clear arc, consistent characters and vivid scenes. The writer keeps a running story bible (characters, places, open threads) so later chapters stay consistent, and you can steer the plot at any point.

Looking for the “Unbound Limitless Story Writer” GPT?

Custom GPTs in ChatGPT are being retired. Long-Form Story Writer does the same job and works in both Claude and ChatGPT, with clear instructions and no sign-up.

Try asking

  • “Write a story about a fallen kingdom”
  • “Create a tale of betrayal and power in a desert empire”
  • “Start a sci-fi mystery aboard a generation ship, first chapter”
  • “Continue the story, but make the hero lose everything”

Add it to Claude

Claude (web, desktop, mobile)

Open Customize → Directory in Claude, search for Long-Form Story Writer and add it. The plugin also works in Cowork and in Claude Code.

Claude Code

/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install long-form-story-writer@plugins-factory

Use it in ChatGPT

Open Plugins in ChatGPT and search for Long-Form Story Writer. Listing in the ChatGPT directory is in review; the package is available in the source repository.

FAQ

Is it free?

Yes. Long-Form Story Writer is free and open source under the MIT license. It runs inside your existing Claude or ChatGPT account.

Does it collect my data?

No. It is a set of instructions for the assistant; it does not call external services or store anything. Your conversation stays in Claude or ChatGPT.

Is this the same as the "Unbound Limitless Story Writer" GPT?

No, it is an independent assistant built to do the same job after custom GPTs were retired. It works in Claude as well as ChatGPT.

Which languages does it support?

It follows the language you write in. English is the default.
