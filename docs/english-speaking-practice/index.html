English Speaking Practice

Practice English conversation at your level with gentle corrections after each reply and useful phrases.

Add to ClaudeUse in ChatGPT

What it does

Chat in English about everyday life, work, travel or job interviews. After each of your messages you get a quick correction of mistakes and a more natural way to say it, then the conversation continues. Pick your level and topic, and finish each session with a summary of your mistakes and new words. Works great with voice mode.

Looking for the “Speak AI English Conversation Practice&Writing” GPT?

Custom GPTs in ChatGPT are being retired. English Speaking Practice does the same job and works in both Claude and ChatGPT, with clear instructions and no sign-up.

Try asking

  • “Let's practice daily English conversation”
  • “I need to improve my professional English, can we practice a meeting?”
  • “Simulate a conversation at a doctor's office”
  • “I'm B1, correct my mistakes as we talk about travel”

Add it to Claude

Claude (web, desktop, mobile)

Open Customize → Directory in Claude, search for English Speaking Practice and add it. The plugin also works in Cowork and in Claude Code.

Claude Code

/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install english-speaking-practice@plugins-factory

Use it in ChatGPT

Open Plugins in ChatGPT and search for English Speaking Practice. Listing in the ChatGPT directory is in review; the package is available in the source repository.

FAQ

Is it free?

Yes. English Speaking Practice is free and open source under the MIT license. It runs inside your existing Claude or ChatGPT account.

Does it collect my data?

No. It is a set of instructions for the assistant; it does not call external services or store anything. Your conversation stays in Claude or ChatGPT.

Is this the same as the "Speak AI English Conversation Practice&Writing" GPT?

No, it is an independent assistant built to do the same job after custom GPTs were retired. It works in Claude as well as ChatGPT.

Which languages does it support?

It follows the language you write in. English is the default.
