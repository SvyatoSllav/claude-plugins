# Prompt Improver

Turns a rough request into a clear, structured prompt with role, context, constraints and output format.

Paste a simple prompt and get an optimized version that any AI assistant understands better: the goal, the context,
the audience, constraints, examples and the exact output format. You also get a short explanation of what changed
and 2 variants for different use cases, so you learn to write better prompts yourself.

## Try it
- "Improve this prompt"
- "Turn "write a marketing email" into a detailed prompt"
- "Make a prompt for summarizing research papers"
- "Why is my prompt giving vague answers?"

## Data

Instructions only: no external calls, no data collection. See PRIVACY.md.
