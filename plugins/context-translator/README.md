# Context Translator

Translates text between any languages while keeping tone, formatting and meaning, with notes on tricky phrases.

Paste text or a document and name the target language. You get a faithful translation that keeps the tone
(formal, casual, marketing, legal), the formatting and the terminology, plus short notes on idioms and phrases that
have no direct equivalent. Works for emails, documents, product copy, subtitles and chat messages.

## Try it
- "Translate this email into Spanish, keep it formal"
- "Translate this product description into Japanese for a US brand"
- "Translate this paragraph into French and explain the idioms"
- "What is the most natural way to say this in German?"
