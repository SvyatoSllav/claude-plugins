# Plugins Factory for Claude

Free assistants for Claude, Cowork and Claude Code. Each folder in `plugins/` is one plugin with its own README, PRIVACY.md and LICENSE.

## Install in Claude Code

```
/plugin marketplace add SvyatoSllav/claude-plugins
/plugin install <plugin-name>@plugins-factory
```

## Plugins

| Plugin | What it does |
|---|---|
| [Context Translator](plugins/context-translator) | Translates text between any languages while keeping tone, formatting and meaning, with notes on tricky phrases. |
| [Cover Letter Writer](plugins/cover-letter-writer) | Writes a tailored, concise cover letter from your resume and the job posting, in a natural voice. |
| [Email Writer by Tone](plugins/email-writer-by-tone) | Writes and replies to emails in the tone you choose, professional, polite, friendly or firm, clear and concise. |
| [English Speaking Practice](plugins/english-speaking-practice) | Practice English conversation at your level with gentle corrections after each reply and useful phrases. |
| [Flirty Reply Coach](plugins/flirty-reply-coach) | Helps you write witty, respectful replies and openers for dating apps and chats, in your own voice. |
| [Grammar & Clarity Checker](plugins/grammar-clarity-checker) | Fixes grammar, spelling and punctuation, explains each change and suggests clearer wording. |
| [Long-Form Story Writer](plugins/long-form-story-writer) | Writes long, coherent stories chapter by chapter from your premise, keeping characters and plot consistent. |
| [Prompt Improver](plugins/prompt-improver) | Turns a rough request into a clear, structured prompt with role, context, constraints and output format. |
| [Resume Tailor & Job Match](plugins/resume-tailor-job-match) | Tailors your resume to a specific job, scores the match and rewrites bullets with the right keywords for ATS. |
| [SEO Article Writer with FAQ](plugins/seo-article-writer-with-faq) | Writes search-optimized articles for a keyword with an outline, meta title, meta description and FAQ section. |
